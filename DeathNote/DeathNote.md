# Звіт з виконання роботи CTF VM DeathNote


## Тема: Тестування на проникнення та підвищення привілеїв на прикладі вразливої машини "Death Note".
## Мета: Закріпити практичні навички аналізу вразливостей, сканування мережі та експлуатації систем для отримання доступу рівня суперкористувача (root).

## Опис тестового середовища
Хост-система (Атакуюча): Kali Linux (встановлена безпосередньо на ноутбуці як основна ОС).

Цільова система: Вразлива віртуальна машина "Death Note" (VirtualBox).

Мережеві налаштування: Віртуальний адаптер хоста (Host-Only Adapter) / Мережевий міст (Bridged Adapter) для проведення траблшутингу та імітації видимості в різних сегментах мережі.

# Резолвінг доменного імені через файл hosts

Для пошуку розташування системного файлу конфігурації було використано утиліту пошуку: `whereis hosts`

Призначення: `whereis` швидко знаходить файли виконуваного коду, вихідні матеріали та сторінки довідки, пов'язані із заданим ключовим словом.

Для прив'язки виявленого доменного імені `deathnote.vuln` до відповідної IP-адреси цільової машини за відсутності зовнішнього DNS-сервера було відредаговано локальний системний файл конфігурації:

Команда: `sudo nano /etc/hosts`:

## Атака методом брутфорсу (Hydra), отримання доступу до SSH та аналіз знахідок

Для підбору облікових даних та отримання доступу до служби SSH було використано інструмент повного перебору:

Команда: hydra -L user.txt -P notes.txt 10.0.2.6 ssh (примітка: використання альтернативного швидкісного інструменту medusa було відкинуте через технічні проблеми з читанням файлів та підбором значень).

-L — вказує шлях до файлу зі списком користувачів (user.txt).

-P — вказує шлях до файлу зі списком паролів (notes.txt).

# Підвищення привілеїв до суперкористувача (Root) та завершення тестування

Для отримання повного адміністративного контролю над системою було перевірено використання раніше знайденого пароля (kiraisevil) для виконання команд із найвищим рівнем привілеїв:
`sudo -i`

<img width="360" height="90" alt="image" src="https://github.com/user-attachments/assets/525cfb1f-2dcb-4a61-af36-49e20a0fb1a2" />

Дія: Запуск інтерактивної оболонки суперкористувача (root) з перевіркою поточних облікових даних.

Результати виконання та захоплення прапора:
Після успішної аутентифікації було досягнуто рівня доступу root. Для подальшої перевірки та фіксації результатів проникнення було виконано перехід до домашньої директорії суперкористувача та виведено вміст файлів:

Команди:

`cd /root` (зміна робочого каталогу на домашню директорію системного адміністратора).

`ls` (перелік файлів у директорії для пошуку фінального артефакту).
